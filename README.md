# 岁岁念 · v2.3

一个把「家人的日子」和「上班动力」缝在一起的 Chrome 扩展。前身叫「宝宝年龄记录器」，v2.3 起改名「岁岁念」—— 记着每一个人，也记着自己为什么上班。
数据全部存在本机 `chrome.storage.local`，不联网、不上传。

## v2 做了什么

### 成长
- 精确年龄：`x岁x个月x天`，用「先估月份 + 锚点回退」算法，月末、闰年、2 月 29 日都不会算错
- 第 N 天 / 已陪伴天数 / 周数 / 小时数
- 下一个里程碑倒计时：整月、100 天、1000 天、周岁，自动挑最近的那个，带进度条
- 星座、生肖（生肖按春节分界，覆盖 2015–2030）
- 下次生日倒计时；生日当天自动撒花

### 农历生日（v2.1）
- 档案里直接显示农历生日，例如「五月十三」；闰月出生显示「闰二月初四」
- 同时给出下次公历 / 下次农历两个倒计时
- 农历生日也算里程碑候选，离得最近就顶到「下一个里程碑」卡片上
- **提醒**：每天 09:00 由后台 service worker 检查，农历生日当天和前一天各弹一条浏览器通知，可在设置里关闭
- 算法是 1900–2100 的万年历查表（`lunar.js`），不是浏览器内置的 `Intl` 农历
  - 原因：ICU 的 chinese 日历在 2027、2030 等年份会差一天（2027 春节实际是 2 月 6 日，ICU 算成 2 月 7 日），而且结果受系统时区影响
  - 已用 17 个已知日期交叉验证：1900/1984/2000/2010/2024/2026/2027 春节、2023 闰二月、2020 闰四月、2017/2025 闰六月、端午中秋等，全部一致
  - 腊月三十出生、当年腊月只有廿九时，自动按「当月最后一天」提醒

### 工位（上班动力）
- 下班倒计时：上班时段打开扩展，默认就落在这一页
- 今日已赚 = 时薪 × 已工作时长占比，并折算成「几罐奶粉 / 几片尿不湿」
- 休息日自动切到「好好陪宝宝」，不算钱
- 每日一句「今天为什么值得上班」
- （v2.2 起移除了 25 分钟番茄钟）

### 成就 / 可玩性
- 摸宝宝头像：爱心粒子 + 连击计数 + 合成音效「咯咯」+ 随机台词，每次 +1 金币（每天上限 40）
- 等级：青铜 → 白银 → 黄金 → 铂金 → 钻石 → 王者养娃人
- 连续陪伴打卡（14 天格子），跨天自动续，断签重置
- 10 个成就徽章，解锁时弹 toast
- 完整的浅色 / 深色主题，跟随系统

## 修复的旧问题

| 旧版问题 | v2 |
|---|---|
| 名字直接拼进 `innerHTML`，可 XSS | 全部 `textContent` / 安全构建 DOM |
| `formatAge` 在 0 天时返回空字符串（新生儿当天什么都不显示） | 永远至少显示「0天」 |
| 未来日期可以添加，年龄算成负数 | 校验并提示「出生日期不能晚于今天」 |
| 头像原图 Base64 直接入库（几 MB，撑爆 5MB 配额） | canvas 裁剪压缩到 160×160 JPEG，通常 < 15KB |
| 只有「添加 / 删除」，改名字得删了重加 | 支持编辑；删除改为「再点一次确认」，不再弹原生 confirm |
| `console.log` 满屏 | 清理 |
| 只有 16px 一个图标 | 16/32/48/128 全套，工具栏清晰 |

## 安装

1. `chrome://extensions/`
2. 右上角打开 **开发者模式**（Chrome 137+ 起，解压扩展在开发者模式关闭时会被自动停用，表现为「已关闭 / 开启开发者模式即可使用此扩展程序」）
3. 「加载已解压的扩展程序」→ 选中本项目文件夹
4. 点地址栏右侧的拼图图标，把「岁岁念」固定到工具栏

## 数据结构

```js
chrome.storage.local = {
  babies: [{ id, name, birthday: 'YYYY-MM-DD', avatar: 'data:image/jpeg;base64,...' }],
  currentId: '...',
  settings: { start: '09:00', end: '18:00', hourly: 35, milkPrice: 220, lunarReminder: true },
  stats: { coins, pets, happiness,
           streak:{count,last,days:[]}, daily:{date,pets}, unlocked:[], flags:{} },
  notified: { 'lunar-<babyId>-<date>': '<date>' }   // 通知去重，最多保留 60 条
}
```

旧版只写了 `babies`，v2 直接兼容（缺的字段用默认值补齐），老数据不会丢。
设置页里可以导出 / 导入 JSON 备份。

权限只有三个：`storage`（存数据）、`alarms`（每天定时检查）、`notifications`（弹农历生日通知）。
